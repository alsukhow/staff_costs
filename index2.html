Распределение зарплат по юнитам

Сентябрь 2026 · AED

Как зарплата попадает в P&L юнита

Логика файла Shared Salaries: один ключ на сотрудника, одинаковый для всех его выплат месяца.

Ключ сотрудника

В мастере ключей у каждого сотрудника доли по юнитам, в сумме 100%, основание ключа и руководитель, который его подтверждает.

Выплаты месяца

Из payroll за сентябрь берутся все выплаты сотрудника: пакет (оклад, жильё и транспорт по контракту), комиссии, part-time, HRA, персональные тренировки, сверхурочные, транспорт, связь.

Разнесение

Каждая выплата делится по ключу: сумма юнита = выплата × доля юнита. Исключение — комиссии: они относятся на юнит, где заработаны.

Проводка в P&L

Доли юнитов ISD ложатся на счета Salaries и Salaries Shared (FC, RS, ISD). Доли Kickers, La Famiglia, Caffelini и RMF перевыставляются из ISD и видны в их P&L как Shared Employee Cost – ISD (у RMF — Salaries Shared ISD).

Ключи общих сотрудников

По умолчанию сначала те, кто делится на большее число юнитов, внутри — по сумме: весь бэк-офис, который работает на все проекты, стоит сверху. Заголовки сортируют, в том числе по департаменту.

Основания ключей

Кто и как задаёт доли, по формулировкам файла. Суммы — все выплаты сотрудников с этим основанием.

Затраты по департаментам

Департаменты по файлу. Сначала те, чьи затраты больше всего делятся между юнитами; доля общих — сколько из суммы делится по ключам.

Состав затрат по юнитам

Пакет — оклад с жилищной и транспортной надбавкой по контракту. Остальные колонки — переменные выплаты сентября и ретейнер Adhoc.

Реестр

Все сотрудники сентября и ретейнер Adhoc. По умолчанию — по числу юнитов, затем по сумме; заголовки сортируют. «Расчёт» показывает разнесение каждой выплаты по ключу.
